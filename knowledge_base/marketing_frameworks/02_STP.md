# STP — Segmentation, Targeting, Positioning

Segmentation divides customers into meaningful groups.

Targeting chooses which groups or customers receive marketing resources.

Positioning defines how the offer should be perceived by the intended customer.

Use STP for:
- target selection
- segment comparison
- resource allocation
- differentiated marketing

Project application:
K-Means creates four business-oriented customer segments.

Segment 3 has the strongest response opportunity.
Segment 4 has the strongest financial-value opportunity.
